# If your antivirus flags this

A small unsigned executable that opens a socket and reads input devices is a
heuristics magnet, and at least one vendor will probably flag a release at
some point. If yours does:

1. Verify the file came from this repository's public CI (docs/VERIFY.md §4).
   If verification FAILS, delete the file and open an issue immediately.
2. If verification passes, it is a false positive. Vendor false-positive
   report forms are linked below; a VirusTotal link for each release is
   attached to the release notes.

(Per-vendor links to be filled in the first time each vendor flags us.)
